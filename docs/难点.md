# slint不能最大化
通过让ai检索官方文档解决。

原因是 Slint 根窗口使用了固定尺寸：

```slint
width: 1220px;
height: 760px;
```

Slint 会把根组件的布局约束传递给 Windows。固定 `width/height` 会让窗口的最小尺寸和最大尺寸相同，因此 Windows 将它判断为不可调整大小的窗口，标题栏最大化按钮也随之禁用。

正确写法是提供首选尺寸和可变化范围：

```slint
preferred-width: 1220px;
preferred-height: 760px;
min-width: 900px;
min-height: 640px;
max-width: 100000px;
max-height: 100000px;
no-frame: false;
```

修复后窗口拥有：

- `WS_MAXIMIZEBOX`：允许标题栏最大化
- `WS_THICKFRAME`：允许拖动边框调整尺寸
- 原生最小化、最大化和关闭按钮

另外，重做布局时曾出现子元素尺寸引用父容器、父容器尺寸又由子元素决定的绑定循环，导致栈溢出。这是另一个问题，不是最大化按钮最初被禁用的直接原因。
